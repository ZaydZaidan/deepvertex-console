## Continuation — ArduSub/QGC tech-spec reconciliation (12 Oct, late night)

A deep-research pass over official ArduPilot/ArduSub/QGC sources was reconciled against
the console; every gap found was fixed and verified (code commit `28ed33e`, console
tests **17/17**):

1. **Motor test (real-ArduSub compliant):** `DO_MOTOR_TEST` now sends `p6=2`
   (`MOTOR_TEST_ORDER_BOARD` — mandatory on Sub) and since Sub ignores the `p4` timeout,
   the dialog re-sends every 0.4 s (500 ms watchdog; without it the test aborts and the
   vehicle auto-disarms) plus a final stop command. Dialog documents: ROV must be ARMED
   with the hardware safety switch released; motor instance 0/1-based = VERIFY on bench.
2. **Mag calibration (QGC sequence):** CANCEL → START (retry + autosave on) → on
   `MAG_CAL_REPORT` success (`cal_status==3`): if `autosaved==0`, send
   `DO_ACCEPT_MAG_CAL`; message reminds to reboot the autopilot before arming.
   `MAG_CAL_PROGRESS`/`MAG_CAL_REPORT` are now explicitly subscribed — they ride the
   EXTRA3 stream and would otherwise stay silent on the real vehicle.
3. **Pre-arm chip** now driven by the SYS_STATUS `MAV_SYS_STATUS_PREARM_CHECK` bit
   (268435456, QGC pattern); the latest "PreArm:" STATUSTEXT takes precedence.
4. **`ARMING_SKIPCHK`** replaces the legacy `ARMING_CHECK` combo (ArduSub 4.7+ inverts
   the semantics: set bits = checks to SKIP; 0 = run all).
5. **GCS system id 255** (QGC parity; matches default `SYSID_MYGCS`).
6. **Command retry:** a COMMAND_LONG with no ACK for >2 s is re-sent once — excluding
   motor test and all calibration commands (must never auto-repeat).
7. **ARM soft-gate:** arming asks for confirmation while the pre-dive checklist is
   incomplete ("Enforce Preflight" QGC behaviour; the authoritative gate remains the
   ArduSub pre-arm checks).
8. **pymavlink quirks** found en route (already fixed earlier in v2.2): default MAVLink
   v1 truncates `rc_channels_override` to 8 channels (lights ch9+ silently dead) →
   `MAVLINK20=1` set before import; `logfile_raw` never fed on udpin → tlog taps
   `mavfile.recv()`; RAW test agent must be started with `--port 8791`.
