DeepVertex ROV Console — saved files
====================================

Everything you SAVE from the console lives here:
 failsafe.json FAILSAFE & BATTERY panel → SAVE FILE
 params_<timestamp>.json PARAMETERS panel → SAVE… (full parameter dump)

LOAD FILE / LOAD… read files from this folder by default.
Per-dive media (video / photos / RAW) does NOT go here — see
~/DeepVertex-ROV-Captures/<date>_dive/ (compressed/ and raw/).
